# YORVA Document Review

Use this Skill when the user asks to review a proposal, specification, plan, report, or other prose document.

Read `references/review-checklist.md` before reviewing. Base findings only on the supplied document and clearly distinguish observed facts, reasonable inferences, and unanswered questions.

Lead with the most consequential findings. For each finding, identify the affected section, explain the practical impact, and suggest the smallest useful correction. Do not invent missing evidence or claim that an external fact was verified unless it was actually checked.

End with a short prioritized action list. If the document is already sound, say so directly and mention any remaining verification limits.
